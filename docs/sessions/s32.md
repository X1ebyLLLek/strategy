## Как делать новые модели (рабочий путь облака)
- poly.pizza, kenney.nl и Sketchfab из контейнера не открываются. Работают: **opengameart.org** (поиск
  `/art-search?keys=…&field_art_type_tid[]=9` — 3D; страницы `/content/<имя>`, файлы
  `/sites/default/files/…`), quaternius.com (скачивание — Google Drive, «Quota exceeded»), api.polyhaven.com
  (CC0, glTF с текстурами 1k; пушка `cannon_01`, винтовка `bolt_action_rifle_7_62`).
- Конвертер: `apt-get install assimp-utils`; `assimp export a.fbx a.obj` (dae/fbx → obj), `pip install trimesh
  fast-simplification scipy pycollada`. `.blend` старых версий читать нечем (`bpy` ставится минут 20, не дождались).
- Проверять: смотреть **модель целиком с четырёх сторон** до запекания (`tools/…` не хранит просмотрщик; он — 40 строк
  numpy+PIL: рисовать треугольники по глубине).
