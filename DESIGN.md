# Глобальная стратегия (рабочее название: strategy)

Как HOI4, но: нормальная многопоточность, каждый раз новая карта, умный ИИ,
нелинейные технологии, политика без заранее прописанных ивентов.
Каждая партия — своя история.

## Решения (2026-10-14)
- Язык: **Rust**. Карта: **2D** (провинции, как в HOI4) — 3D в глобалке смысла мало.
- Порядок: симуляция без графики → карта → технологии → политика/ИИ → красивая графика.
  Каждый шаг маленький и с быстрой проверкой, что оно живёт.

### Код
Правило (с 20-й): модуль `x.rs` держит типы и общее, его части — в папке `x/`; файл больше ~750 строк режется по смыслу.

**Ядро (библиотека) — `src/`**, ничего не знает об эпохе (всё об эпохе — в наборе `packs/*.toml`):
- `pack.rs` — набор эпохи: товары, группы людей, отрасли, ресурсы, роды войск, роты, техники, стадии
  (+ `pack/read.rs` — вид TOML со значениями по умолчанию и разбор, ошибки моддеру словами);
- `rng.rs` (случайность, одинаковая везде), `noise.rs` (шум Перлина), `png.rs` (запись картинок);
- **`world/` — мир**:
  - `map.rs` (высоты, моря, климат, местность, провинции; самопроверка карты — тест `map_and_countries_hold_together`),
    `shapes.rs` (очертания границ для вида вблизи), `render.rs` (картинка фронта, реки), `names.rs` (имена, склонение
    числительных `plural`);
  - `countries.rs` (кто где живёт и кому принадлежит: люди, развитие, ресурсы, области, страны);
  - `history.rs` — **четыреста лет до игры** (`History::of`) + `history/wars.rs` (войны прошлого: кто с кем и почему,
    коалиции, малые войны, большие войны фронтом, условия мира, отпавшие края) + `history/order.rs` (как страна живёт и
    правится год за годом: голод, перевороты, веры, первый строй, год отношений);
  - `polity.rs` — общество и строй (+ `polity/faith.rs` — веры и заветы, `polity/year.rs` — год общества: силы,
    настроения, движения, смута, законность; революции, перевороты, реформы);
  - `diplomacy.rs` — мнения стран друг о друге с причинами, договоры, войны коалициями;
  - `folk.rs` — люди мира (`Folk`, `Person`, должности, связи) + `folk/life.rs` (рождение, учитель, смерть, год людей) +
    `folk/posts.rs` (должности: назначить, снять, выбрать, генералы войны, переворот, склонности правителя);
  - `progress.rs` — техника эпохи (`Know`: что знает страна, стадия, исследование, заимствование);
- **`economy/` — хозяйство**:
  - `nation.rs` — рынок одной страны (`Nation`, `Month`, `step`) + `nation/`: `prepare.rs` (первая половина месяца),
    `market.rs` (заявки, привоз, цены), `finish.rs` (раздел товаров, платы, запасы, недовольство, рождения и смерти),
    `army.rs` (казна на армию, жалованье, призыв и закон о призыве `LAWS`, потери, уступленная и занятая земля);
  - `trade.rs` — торговля между странами; `advisor.rs` — советники-экономисты; `science.rs` — лаборатории и учёные;
- **`military/` — война**:
  - `battle.rs` — бой (рода войск из набора, ширина, укрытие, усталость);
  - `doctrine.rs` — генштаб и доктрина из опыта (`Country`) + `doctrine/`: `norm.rs` (норма оснащения), `games.rs`
    (штабные игры, норма по ценам, пересмотр плана), `learn.rs` (как штаб учится: бои, разведка, итог войны, учения),
    `duel.rs` (война двух стран на одном фронте — песочница доктрин);
  - `front.rs` — фронт на карте и группы армий (`Campaign`, `Group`, `General`, `Theatre`) + `front/`: `sectors.rs`,
    `staff.rs`, `supply.rs`, `month.rs`;
  - `corps.rs` — **война дивизиями** (как в HOI4: `Shape`, `Division`, `Fight`, `Corps`; `line_first` — дивизия
    вокруг линии, 25-я) + `corps/`: `muster.rs`, `ways.rs`, `orders.rs`, `day.rs`, `fight.rs`, `generals.rs`, `judge.rs`,
    `staff.rs` (генштаб: дивизии по карману, свой образец, армия в мире, мобилизация, предел дивизий на провинцию);
  - `homefront.rs` — тыл: экономика даёт армию (`Homefront`; `footing` — военное положение каждой стороны, 25-я; 26-я:
    `retire`, `equip_cap` — закупки по нужде, `side`/`side_got` — другие заказы из денег армии (флот, обслуживание),
    `war_use` — расход снабжения по интенсивности боёв);
  - `navy.rs` — **флот** (26-я): задачи эскадр, корабли и эскадры, морской бой, потери торговли от рейдов и блокады
    (корабли эпохи — `[[ship]]` набора, `pack::Ship`).
- Рычаги, которые включает только игра (в ядре по умолчанию — старый путь, логи проверок те же до бита):
  `Campaign::depth_k`, `most_battalions`, `most_groups`, `line_first`, `most_per_front`, `grade`, `fixed_armies`,
  `establish`; `Corps::fresh_drill`; `Homefront::footing`, `retire`, `equip_cap`, `side`, `war_use`; у `Nation` —
  нейтральные рычаги финансов (22-я), `cadre_share/cadre_pay`, `army_side` (26-я); `trade::World::hamper` (26-я);
  `wage_by`, `mobility_k`, `growth_by`, `famine_k`, `civil_by` (27-я); у общества — `Life::schooling`, `Life::wealth` (27-я);
  `Campaign::scale` — ширина провинции против обычной: ход, снабжение, прокорм, участки — в настоящем расстоянии (28-я;
  в игре мир — 9000 провинций, `main.rs::PROVINCES`, `map_params`, `prov_scale`).

## Запуск
`play.bat` или `cargo run --release --features native --bin play -- --native [--seed N] [--pack packs/x.toml]` → игра в
своём окне; `--load FILE` — с сохранения (`saves/*.save`).
`play --selftest` — проверки часов; `play --savetest [--pack …]` — самопроверки сохранения; `play --econtest [--pack …]
[--seed N] [--control]` — самопроверки хозяйства и власти (27-я: призрение, школы, врачи, кредит, облигации, неволя,
налог; `--control` — механизмы 27-й выключены, все должны упасть; `ECON_SPOIL=1` — то же в любом режиме, `ECONDBG=1` —
настроения сил по частям и люди по годам, `ECONDBG2=1` — деньги по месяцам при двух ставках);
`play --native --uitest [--pack …] --seed N [--control]` — самопроверки окна (37 с 28-й) (без `--seed` мир случайный; `--control` —
испорченное окно, все проверки должны упасть); `play --native --shot FILE [--tab army] [--design 0] [--zoom 2.5]
[--mode Недра] [--prep-war M] [--play]` — снимок окна (`--tab army:3` — папка на своей странице);
`play --auto [--war-at 36] [--war-months 60] [--log DIR] [--seed N]` — боты за обе стороны, игра пишется в лог (хроника,
`months.csv`, `battles.csv`, картинки фронта); `DIVDBG=1` — каждый месяц: где стоят дивизии, шаблон генштаба, нехватки;
`play --world [--seeds N]` — отчёт о мире (`DBGWARS=1` — перенос краёв).

Проверки ядра — `cargo run --release --bin checks -- <набор> …` (или `target/release/checks.exe <набор> …`):
- `checks battle [--pack packs/x.toml] [--battles N]` → войска эпохи, хроника боя, «кто кого» при равной цене, проверки боя;
- `checks doctrine [--pack …] [--worlds N] [--months M]` → хроника одной войны + проверки доктрин; `--caution`;
  `--history [--seed N]` — две войны с 15 годами мира между ними;
- `checks front [--seed N] [--pack …] [--months M] [--quick]` → война соседей: хроника, `out/front.png`, проверки фронта
  (`--twins --even --swap --luck N --every M`; `BYMAP=1`, `BANDS=1`, `CALIB=1` — разбор); `--groups` — группы армий;
  `NOSHUFFLE=1` — контроль: равенства решаются по номеру; `OLDPOCKETS=1` — котлы по-старому;
- `checks corps [--pack …] [--seed N] [--months M]` → война дивизиями (`--quick` — хроника, `--checks` — проверки;
  `RICH=2`, `GAPS=1`, `DAYS=1`, `WARS=1`; `STACKS=1` — кто стоит в самой большой стопке);
- `checks nation` → три эпохи на карте + проверки; `--pack packs/x.toml` (в т.ч. `packs/toy/t1_one.toml`, `t2_two`,
  `t3_chain`), `--trace packs/x.toml [месяцев]`, `--trace0`, `--country packs/x.toml Имя [месяцев]`, `--calm`,
  `--good packs/x.toml id [месяцев]` (`WHO=id`, `YEARS=id`, `COUNTRY=Имя`, `BYGROUP=1`, `FROM=…`);
- `checks trade` → игрушки торговли + проверки; `--map packs/x.toml [seed]` → 30 стран карты с торговлей и без
  (`WHY=1`, `SWING=1`, `SOLO=1`, `CMP=1`, `ROUTE=id`, `OFF=1`, `LACK=1`, `SOLVER=1`, `TRACE=Страна [GOOD=id]`,
  `EVERY`, `KIND`, `LOSERS`); `--open`, `--open1`;
- `checks advisor [--pack …] [--seeds 1,2] [--countries N] [--months M]` → советники-экономисты (`--techno [--liberal]`,
  `--decomp`, `--levers`, `--alone`; `CASES=0,2`);
- `checks homefront [--pack …] [--seed N] [--quick] [--twins]` → тыл + проверки войны; наборы `--army`, `--econ`,
